# Категорії товарів

У системі "Електронний магазин торгівлі народними промислами" передбачено такі основні категорії товарів:

1. "Кераміка" — глиняний посуд, декоративні тарілки, вази.
2. "Вишивка" — вишиванки, рушники та текстильні вироби.
3. "Різьблення по дереву" — дерев'яні прикраси, скриньки, сувеніри.
4. "Ткацтво" — килими, доріжки, ткані аксесуари.
5. "Писанкарство" — традиційні писанки та декоративні вироби.
6. "Лозоплетіння" — кошики, плетені меблі та елементи декору.
