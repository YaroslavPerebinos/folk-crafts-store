# Електронний магазин торгівлі народними промислами

Навчальна програмна система, присвячена продажу виробів українських майстрів: кераміки, вишивки, різьблення тощо.

## Основні функції (наскрізний проєкт)
Каталог товарів, пошук і фільтрація, кошик, оформлення замовлення, кабінет майстра та модерація. На поточному етапі реалізований лише навчальний API каталогу.

## Технології
Node.js (стандартна бібліотека HTTP), JavaScript, Git. Подальший розвиток передбачає реляційну базу даних та клієнтський інтерфейс.

## Запуск
1. Установити Node.js 20 або новіший.
2. Виконати `npm start` у каталозі проєкту.
3. Відкрити `http://localhost:3000/api/products` (або `/api/products?search=кераміка`).

## Тестування
`npm test`

## Мета проєкту
Проєкт електронного магазину виробів українських народних майстрів із каталогом товарів.
Мета — ознайомлення з Git, GitHub та процесами розроблення програмних систем.
